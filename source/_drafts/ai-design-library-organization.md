之前试过用 Sketch MCP 和蓝湖 MCP 辅助还原设计稿。这次想解决另一个问题：已经积累了很多年的设计稿，怎么重新整理。

原来的设计库里，有些目录按功能分，有些按需求分，还有些用日期或版本号命名。同一个功能的页面散落在不同地方，想整理时，既要找出它们，又要决定新位置，再回到设计工具里移动。

这次尝试里，我觉得最有意义的一步，是先把页面整理到 Excel。整个过程按“名称初分、检查组件元素、人工检查并修正”的顺序推进，分类结果和处理建议都记录在表格中，再以它为依据操作 Sketch。

## 先把页面变成一份可操作的清单

第一步是盘点蓝湖里的项目和页面，再对照本地 Sketch 文件，整理到 Excel 中。这样可以把分散在设计工具里的内容放到一起查看，筛选、排序，也方便记录每一张图准备怎么处理。

表里需要同时保留原始信息和整理后的目标。按用途归纳，主要有这些内容：

| 信息 | 记录内容 | 后续用途 |
| --- | --- | --- |
| 原始来源 | 项目、原名称、原编组、日期、蓝湖链接与 ID | 回到原稿，核对出处 |
| 对应对象 | Sketch 画板或对象 ID、当前候选 ID | 定位源文件里实际要操作的对象 |
| 目标位置 | 新的功能目录及各级分类 | 明确页面要放到哪里 |
| 处理建议 | 归位、保留、重命名、重复稿或旧稿核对等 | 筛选不同类型的工作 |
| 判断与疑点 | 归类结论、待确认原因、相似稿线索 | 继续复查，并记录修订依据 |

例如，一张图原来在某个迭代需求下面，整理后准备放到“通讯录／通讯录搜索”，就把原位置和目标位置都留下。后面检查时，可以看到这次移动的来龙去脉，也能继续修正目标目录。

实际表格分了几张工作表。“目录”看整体结构，“目录+页面”展开到具体页面，“分类操作”记录逐项处理。后面操作了 Sketch，又补上“Sketch目录”和“Sketch目录+页面”，对照文件里实际保存的结果。

## 第一轮按名称分类，先建立整体结构

页面很多时，我先让 AI 根据名称和原有编组做一轮分类。

比如，名称里能看出登录、消息、通讯录或日程的页面，先归到对应业务模块；再往下细分到具体功能和场景。原来按需求命名的一组图，也可以在这一步拆到各自的功能目录里。

这一轮主要是把散落的页面放进一套可以检查的结构。表格里既能按新目录查看某个功能有哪些稿，也能筛出同名多稿、旧版本稿和暂时无法确定位置的内容。

对我来说，Excel 在这里比一段整理建议更实用。目录怎么分可以写在文档里，但几千条页面具体落在哪里，需要逐项列出来。后面要调整分类，直接修改对应记录，就能保留已经整理过的其他部分。

## 第二轮检查组件和页面元素，再细化归属

有了初步分类后，再检查页面内部的组件、图层、可编辑文案和主要操作，补充名称里没有表达清楚的信息。

“搜索”就是一个很具体的例子。光看名字，只知道它是一张搜索页；继续看搜索范围、结果分类和操作入口，才能把它放到全局搜索、通讯录搜索或群内聊天记录搜索中。

机器人相关页面也一样。通讯录里的机器人入口、群内添加机器人的流程、聊天里的机器人会话，属于不同的使用场景。检查界面元素后，再把细分归属更新到 Excel 的分类操作记录中。

同名和近似稿也放在这个阶段继续比较。先找到对应的 Sketch 对象，再比较布局、同位置文案等信息，把相似度和候选对象写进表格。这样人工复核时可以先筛出一批接近的稿件，集中查看。

原来的来源信息仍然保留，新的归类结论另外记录。这能让每一轮检查接着上一轮继续做，也方便追查某张图为什么被放进这个目录。

## 人工检查后修正，再按表操作 Sketch

接下来由我检查熟悉的业务，结合实际页面修正分类和处理建议。检查时可以按功能目录、同名多稿、旧稿或待确认原因筛选，逐批处理。

有些页面已经能确定功能归属，只是还没决定保留哪个版本。这两件事可以分别记录：先归到明确的目录，把相似稿放在一起，后面再检查删留。这样每轮检查都有具体进展。

表格中的“分类操作”也就成了后续整理 Sketch 的依据。操作时，根据当前文件里对应的画板或对象 ID，找到要处理的内容，再按目标目录归位。名称用于阅读，ID 用来确定实际对象；同一对象有多条来源记录时，执行前还要按实际 ID 去重。

这次实际整理保留了最近几个版本的独立目录，其他页面按功能归位，组件和控件集中到设计规范，同名、近似稿放在一起方便筛选。整理结果另存为新的 Sketch 副本。

移动之后，还需要把同一目录下的画板重新排列，收紧空位，调整间距。再把实际位置同步回 Excel，后面就能按表格里的目录和对象 ID 继续找到对应设计。

对我来说，这份 Excel 把页面盘点、分类判断、人工检查和文件操作连在了一起。它既能让我集中查看设计库，也能把“这张图要怎么处理”变成后续可执行的记录。

目前内容量还是很大，部分分类和版本判断仍可能需要修正，整体效果也还没完全达到预期。但“先按名称整理、再检查元素、人工复核后修正，并以 Excel 为依据操作”的流程，我觉得值得继续用下去。
